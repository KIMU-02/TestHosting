요청 경로별 응답

PostgreSQL 연결과 잠금

최근 오류 · 최대 10건

이상이 보이면 무엇부터 확인하나요?
  1. DB 확인 불가: Docker Desktop에서 db 컨테이너와 로그를 확인합니다.
  2. 잠금 대기: 아래 대기 PID와 차단 PID를 확인합니다. 원인을 확인하기 전에 세션을 강제 종료하지 마세요.
  3. 5xx 증가: 요청 ID로 API 로그를 찾아 같은 요청의 상태를 확인합니다.
  4. 4xx만 증가: 품절·입력 오류·중복 키 충돌일 수 있습니다. 서버 장애와 구분합니다.

아래 성능 실험 보고서는 과거 실측입니다. 여기의 운영 p95는 실제 요청 구성과 DB 연결 시간에 영향을 받습니다.

결과를 해석할 때

인덱스 존재 여부만 바꾸고, 동일 SQL과 고객 순서를 사용했습니다. 각 구간에서 워밍업 후 인덱스 전·후·후·전(ABBA)을 반복했습니다.

OS 캐시를 비우지 않았으며 인덱스 생성도 캐시에 영향을 줍니다. 단일 연결의 조회 지연 시간으로, 전체 서비스 처리량·인덱스 쓰기 비용·통계적 유의성을 측정한 결과는 아닙니다.

이 결과는 표시된 시각의 코드로 측정한 기록입니다. 현재 화면의 실시간 성능이 아니며, 같은 환경에서도 결과는 달라질 수 있습니다.
